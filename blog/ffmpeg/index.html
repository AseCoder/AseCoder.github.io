FFMPEG cheatsheet

These are some useful command templates for converting and wrangling photos, videos and GIFs with command line tools like FFMPEG and ImageMagick. Many of these are specific to me and my hardware.

FFMPEG

ffmpeg -hwaccel cuda -i "" -c:v h264_nvenc -preset p7 -qp 34

Explanation

Read a file or URL with Cuda hardware acceleration and encode to H.264 with hardware acceleration, a slow preset and constant quality (smaller is better).

ffmpeg -hwaccel cuda -i "" -c:v h264_nvenc -preset p7 -rc-lookahead 55 -multipass fullres -bufsize 2M -b:v 900k

Explanation

Read a file or URL with Cuda hardware acceleration and encode to H.264 with hardware acceleration, a slow preset, rate control (lookahead frames, buffer size), two passes and a constant video bitrate.

Discord tip: for the maximum file size of 20 MB and video length t, the maximum bitrate is
20 (MB) / t = 160 / t (Mb/s)

-c:v hevc_nvenc -tag:v hvc1

Explanation

For H.265 (HEVC) encoding. Use -tag:v hvc1 to ensure compatibility with Apple devices.

ffmpeg -i "" -vf "select='eq(pict_type,PICT_TYPE_I)'" -vsync vfr thumb%04d.png

Explanation

Output one image for every I-frame. %04d means that the ordinal number of each output image will be formatted using four digits. Similar to number formatting in the C language.

ffmpeg -i "images\%4d.png" -r 10 animation.gif

Explanation

Image sequence to 10 fps GIF. There are more options that can make GIFs look better, because they're limited to 256 colours.

ffmpeg -i url.mp4 -vf "scale=640:-1:flags=lanczos,split[x1][x2]; [x1]palettegen=stats_mode=single[p]; [x2][p]paletteuse=new=1" output.gif

Explanation

Convert the input video to a GIF. Scale to 640 pixels on one axis and retain the aspect ratio (:-1). Generate a palette of the colours in the video instead of using the default GIF palette.

ffmpeg -hwaccel cuda -i ".mov" -filter_complex "[0]trim=end_frame=24,scale=640:-1:flags=lanczos,split[s1][s2]; [s1]reverse[r]; [s2][r]concat=n=2:v=1:a=0, split[x1][x2]; [x1]palettegen=stats_mode=single[p]; [x2][p]paletteuse=new=1" output.gif

Explanation

Back and forth GIF. Only includes the first 23 frames of the input video, scales it as above, concatenates the clip in reverse, and generates a custom palette.

-ss 1:40.9

Explanation

Seek exactly to 1 minute and 40.9 seconds in the video. This is an input parameter (goes before -i).

-frames:v 50

Explanation

Take a number of frames from the input. Similar to the time-based -t [seconds].

-f concat -i mylist.txt -c copy

Explanation

If the input videos have the same parameters, you can make a list of them in mylist.txt:

file '/path/to/file1'
file '/path/to/file2'
file '/path/to/file3'

and pass that file as an input to FFMPEG.

ffmpeg -i file1.mp4 -i file2.mp4 -i file3.mp4 -filter_complex "[0:v] [0:a] [1:v] [1:a] [2:v] [2:a] concat=n=3:v=1:a=1 [v] [a]" -map "[v]" -map "[a]"

Explanation

If the inputs have different parameters and you want to reencode them. If you don't have three inputs, change the filter inputs before "concat" and the n.

-movflags +faststart

Explanation

Optimizes the output video for network playback by moving some data from the end of the file to the beginning, so the user does not have to download the whole file to begin playing.

AAC audio encoding

The best AAC encoder is libfdk_aac. By default it has a 14 kHz lowpass filter. Try -cutoff 18000, but it may reduce quality.

I have to use the aac encoder.

Set bitrate with -b:a 128k.

ffmpeg -i ".tif" -c:v libsvtav1 -vf scale=1920:-1 -crf 1 output.avif

Explanation

This uses AVIF image encoding. -crf sets the quality, in this case very low.

Use the svt-av1-psy encoder instead of libaom-av1.

I don't think I have the psy one. libsvtav1 is the closest one.

The AOM encoder was built to be a textbook example of the AV1 Encoder, to demonstrate it's functions for research purposes. It's a Reference Encoder.

SVT-AV1 was built with efficiency in mind. It leverages modern CPUs' full instruction sets and multiple cores/threads for accelerated operations.

SVT-AV1-PSY is a psycho-visually optimized branch of SVT-AV1. It tunes the baseline parameters of SVT-AV1 (and adds new ones) to be more psychologically lossless per a given bitrate/preset.

(^ Reddit comment)

ffmpeg -h encoder=libsvtav1 for help.

ffmpeg -hwaccel cuda -i "" -c:v h264_nvenc -preset p7 -qp 33 -movflags +faststart -vf "zscale=pin=bt2020:tin=arib-std-b67:min=bt2020nc:rin=tv,zscale=t=linear:npl=700,format=gbrpf32le,tonemap=mobius:desat=2,zscale=p=bt709:t=bt709:m=bt709:r=pc,format=yuv420p" output.mp4

Explanation

Converts iPhone 16 HDR (Dolby Vision) video to SDR.

Nominal peak luminance is 700 (100 would be the default) and desaturation is 2 (2 is the default) and pc blacks instead of tv.

ffmpeg -f lavfi -i anullsrc=channel_layout=stereo:sample_rate=44100 -loop 1 -i "url" -vf scale=x:-1 -t 4 -pix_fmt yuv420p -color_range tv output.mp4

Explanation

Loop one scaled image frame for 4 seconds at undefined framerate. Include silent audio channel.

ImageMagick

magick convert -density 300 ".pdf"[0] -background white -flatten page1.png

Explanation

Using ImageMagick, converts the first (0-index) page of the PDF to a PNG at 300 DPI. Also works with a web URL. Without background and flatten it leaves the background transparent. Might be picky with any weird symbols in the filename. Safest to have a simple filename in the current folder.
